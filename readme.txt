HOW TO PLAY THIS MOD:
A full copy of the original Quake 2 is required to play this mod. Also, it might only work in Windows. Sad!

1. Download the folder named "mariomod" from this branch. It should contain the dll file, a config, and map list.
2. Copy and paste the folder into your main Quake 2 directory, the one containing the baseq2 folder.
3. Right click Quake 2's executable file and create a shortcut. Right click the new shortcut and select "properties".
4. Find the "Target" field within the properties menu. It should contain the location of the .exe file within quotes. Add to the end the command '+set game mariomod', outside of the quotation marks. The target field should now read:
"[Your Quake 2 executable location]" +set game mariomod

If done right, running this shortcut should start Quake 2 within the mod. Start a new game and have fun!
Note that letting the game preview load after the Id splash screen will make the game revert to the unmodded version, make sure to press enter upon opening the game.

FEATURES OF THIS MOD:

1. Armor shards are now coins! Pick up any lying around, or break barrels to find some inside! They don't actually do anything, but gather them anyway!
2. Soldiers no longer shoot, and will instead try to get as close as possible and explode.
3. Infantry similarly can't shoot anymore and, when killed, drop a grenade you can pick up and throw.
4. Sorry, no more small health packs. They are now Chicks who don't move and fire slow-moving rockets.
5. Flyers now drop live grenades.
6. Hovers now cast four wicked spells... if you believe railguns, grenades, bullets, and explosions are considered magic, that is.
